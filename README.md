# このアプリについて
Spectrogram Visualizerです。音声ファイル, 録音のスペクトログラムを可視化するためのツールです。

# 操作方法
| 操作エリア | キーコンビネーション | 動作 |
| :--- | :--- | :--- |
| **スペクトル描画領域（右側）** | ホイールのみ | **通常の左右時間スクロール**（適正速度に調整） |
| **スペクトル描画領域（右側）** | **`Shift` ＋ ホイール** | **ゆっくり左右時間スクロール**（精密な位置合わせ） |
| **スペクトル描画領域（右側）** | **`Ctrl / Command` ＋ ホイール** | 通常の時間軸ズーム（拡大・縮小） |
| **スペクトル描画領域（右側）** | **`Shift` ＋ `Ctrl / Command` ＋ ホイール** | **ゆっくり時間軸ズーム**（精密な拡大・縮小） |
| **描画領域外（左側の鍵盤・目盛り）** | ホイールのみ | 周波数軸の上下移動（パン） |
| **描画領域外（左側の鍵盤・目盛り）** | **`Ctrl / Command` ＋ ホイール** | 周波数軸の拡大・縮小（ズーム） |
| **描画領域外（左側の鍵盤・目盛り）** | **`Shift` ＋ `Ctrl / Command` ＋ ホイール** | **カラー感度（色の強さ）の増減調整** |

to run
```
# 依存ライブラリのインストール
npm install
# アプリの起動（開発モード）
npm run tauri dev
```
